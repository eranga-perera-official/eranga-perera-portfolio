# Eranga Perera — Personal Portfolio

A responsive, dark-themed personal portfolio for Eranga Perera.

## Website
- Homepage: `index.html`
- Styles and layout are embedded in the homepage.
- Built as a static site for GitHub Pages.

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. GitHub will provide the published website address in the Pages panel.

## Before sharing publicly
Update the contact email placeholder in `index.html` (search for `YOUR-EMAIL@example.com`).
Replace the featured project descriptions with final approved work and add portfolio images when ready.
